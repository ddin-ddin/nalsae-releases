# 날쌔 (Nalsae) 배포

날쌔 원격 데스크톱의 공개 배포 저장소입니다.
이 저장소에는 설치 파일, 서명된 자동 업데이트 정보, 릴리즈 노트만 게시합니다. 프로그램 소스코드와 사용자 데이터는 포함하지 않습니다.

Windows 설치 파일: https://github.com/ddin-ddin/nalsae-releases/releases/latest/download/nalsae-installer.exe

첫 릴리즈 전에는 위 링크가 열리지 않습니다.

설치된 앱은 새 버전을 백그라운드에서 받아 두고, 준비되면 알려 줍니다. 앱을 다시 시작하면 업데이트가 끝납니다.

무단 분석·역공학·복제는 허용하지 않습니다. 제삼자 라이선스의 권리는 보존됩니다.

---

Public release downloads and signed auto-update metadata for Nalsae, a low-latency remote desktop app. Source code is not published here.
